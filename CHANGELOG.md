# Changelog

## 0.3.1 — 2026-11-20

First public GitHub release.

- Group tabs locally by registrable root domain using a bundled Public Suffix List.
- Name groups and merge related topics using OpenAI-compatible or Anthropic-compatible APIs.
- Limit model payloads and run at most three requests concurrently.
- Support manual grouping and scheduled organization with second-based intervals, starting at 30 seconds.
- Migrate older minute-based settings without changing their configured frequency.
- Add an ungroup-all action that keeps tabs open.
- Follow Chrome's UI language for English and Chinese, defaulting to English; use English built-in prompts.
- Add toolbar icons, a streamlined popup and settings interface, and a public bilingual privacy policy.

Chrome Web Store status at release: submitted for review, with automatic publication after approval. This GitHub release does not mean the store review has completed.
